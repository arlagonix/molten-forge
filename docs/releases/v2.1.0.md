# Molten Forge 2.1.0

This release refines the chat experience with a live activity timeline, an OpenCode-inspired interface, improved session navigation, and more reliable composer behavior.

## Features

### Activity Timeline

* **Added Semi Compact timeline mode**. `feature`
  The current Thinking and tool-call sequence stays expanded while Pi is working, then collapses into a `Used…` summary when that activity ends.
  Compact and Full remain available; earlier activity can still be inspected on demand.

* **Added clearer tool activity summaries**. `feature`
  Compact groups combine related Thinking and tool calls with tool counts, failure indicators, and expandable details.
  Explicit parallel-call batches remain distinguishable when expanded.

### Message Actions

* **Added message details and actions**. `feature`
  Hovering over a message reveals available model and time information, plus a Copy action without shifting the conversation layout.
  Historical user messages also offer a Pi-backed Fork action when the agent is idle.

## Changes

### Chat Interface

* **Redesigned message bubbles and activity presentation**. `change`
  User messages now fit their content on the right; Thinking and tool rows share lighter borders, consistent alignment, and less visual nesting.
  Thinking content uses upright text for readability.

* **Refined the floating composer and queue layout**. `change`
  The composer starts at one input line, with Steer and model controls together on the left and context/send controls spaced on the right.
  Queued messages line up with the composer, and the scroll-to-bottom arrow tracks its visible top edge.

* **Added an animated active-status label**. `change`
  The Working/Composing label uses a subtle text shimmer during generation, with a static presentation when reduced motion is preferred.

### Appearance and Settings

* **Unified the mountain background across themes**. `change`
  Light and dark themes use the same bundled mountain image by default, with adjustable wallpaper visibility and a consistent chat/composer surface treatment.

* **Simplified Settings navigation and selectors**. `change`
  Settings tabs use one clean selection highlight, while selection controls fit their content and open themed, keyboard-accessible menus.

* **Moved model selection into a centered dialog**. `change`
  The existing Pi model switcher now offers search, recent models, provider sections, and keyboard navigation in a dedicated modal.
  Selecting a model still updates Pi without creating a chat message.

### Project Navigation

* **Prioritized recently opened projects**. `change`
  Newly opened folders appear at the top of the project list, and projects without actual Pi session activity are not retained as recent projects.

## Fixes

### Composer and Navigation

* **Preserved drafts and reading position across reloads**. `fix`
  Reloading with Ctrl+R restores unsent composer text and the prior chat position, including bottom-follow when active.

* **Corrected theme-switch layout updates**. `fix`
  Switching between light and dark now refreshes the chat mask and composer measurements so the fade and scroll-to-bottom control remain aligned.

* **Corrected Copy action feedback**. `fix`
  A successful Copy shows a checkmark briefly, then returns to the Copy icon after 1.5 seconds.
  Repeated clicks restart the confirmation period, and the timer is cleared when the message unmounts.

### Appearance

* **Reduced redundant highlights and spacing artifacts**. `fix`
  Project rows no longer show a second nested hover highlight; Thinking content and the composer have tighter, consistent spacing and surfaces.
