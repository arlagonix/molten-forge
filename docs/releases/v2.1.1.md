# Molten Forge 2.1.1

This release makes completed agent activity easier to review and improves message timing, historical session rendering, and chat controls.

## Features

### Completed Activity

* **Added a completed-run `Worked for …` disclosure**. `feature`
  Compact and Semi Compact now collapse earlier Thinking, tool calls, and intermediate assistant updates after the entire Pi run finishes.
  The final response and trailing error notices remain visible; Full mode continues to show all activity.

* **Displayed elapsed work time**. `feature`
  The completed-run summary and final assistant metadata show the response duration when reliable timing is available.
  Live runs include tool execution, while reopened sessions use Pi's recorded model durations and available tool-result timestamps.

## Changes

### Chat Messages

* **Showed one assistant metadata row per response**. `change`
  Model, date, duration, and Copy controls now appear beneath the final assistant message instead of every intermediate update, reducing vertical clutter.

* **Unified disclosure chevrons**. `change`
  `Worked for …` always displays a directional chevron, and expandable Bash and other tool headers show chevrons on hover instead of the fullscreen icon.

## Fixes

### Activity and History

* **Restored completed-work folding for non-text and failed runs**. `fix`
  Historical turns ending in Thinking, tool calls, or errors can now collapse even without a final assistant text message.
  Terminal errors remain visible outside the collapsed details.

* **Waited for complete Pi run settlement**. `fix`
  `Worked for …` does not appear during an active agent run, including when Steer creates additional user turns before `agent_settled`.

* **Corrected missing and misleading durations**. `fix`
  Historical timings use Pi's model-request metadata rather than the user's prompt timestamp. Unknown durations are omitted, subsecond runs show `<1s`, and longer durations round to the nearest second.

### Chat Layout

* **Aligned chat-width resize markers with the pointer**. `fix`
  The left and right markers now position themselves against the actual rendered resize guide rather than an outdated fixed header offset.
