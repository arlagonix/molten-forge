# Molten Forge 2.0.0

Molten Forge returns with a new Tauri + Pi architecture. This release replaces the previous Electron application; it is not an in-place continuation of its runtime or configuration format. Pi must be installed separately.

## Features

### Pi Integration

* **Rebuilt Molten Forge around the Pi coding agent**. `feature`
  The desktop application connects to a system-installed Pi process through JSONL RPC instead of maintaining a separate agent runtime.
  Pi remains responsible for model providers, agent execution, tools, sessions, extensions, and skills.

* **Added project-aware conversation navigation**. `feature`
  The sidebar organizes Pi sessions by working folder, allows switching projects, and displays conversations by recent activity.
  Project rows provide shortcuts for starting a new session and opening the folder in the file manager.

* **Added Steer and Follow-up messaging during generation**. `feature`
  The composer can queue messages while Pi is already generating, with separate Steer and Follow-up behaviors.
  Queued messages are displayed in a compact strip and can be retrieved for editing through Pi's queue controls.

### Desktop Experience

* **Added integrated model selection and context telemetry**. `feature`
  The composer offers a searchable, provider-grouped model picker alongside token and context usage information.
  Switching models updates Pi without inserting an artificial message into the conversation.

* **Added managed file and image attachments**. `feature`
  Attachments can be selected, pasted, or dropped into the composer, with image previews and managed local storage.
  Session references keep already-sent attachments available when restoring conversations.

* **Added configurable themes and background images**. `feature`
  Light, dark, and system themes support bundled or custom wallpaper selections, with a global visibility toggle.
  Turning images off leaves the saved per-theme choices intact for later use.

## Changes

### Architecture

* **Replaced the Electron desktop shell with Tauri**. `change`
  React and TypeScript continue to render the interface while Rust handles native integration and Pi process communication.
  The application is now distributed as Molten Forge, while existing internal Pi identifiers remain stable to protect stored data.

* **Kept the Pi runtime separate from the installer**. `change`
  Molten Forge launches the locally installed `pi` command rather than bundling or modifying the agent.
  Existing Pi provider settings, extensions, skills, and session storage remain under Pi's control.

### Interface

* **Reworked transcript rendering around virtualized conversations**. `change`
  Long chats use bounded virtualized message rendering, with independent reading and auto-follow behavior.
  Thinking, tool activity, retries, and grouped tool calls retain distinct presentation.

* **Expanded read-only CodeMirror presentation**. `change`
  Markdown code blocks and textual tool input/output use read-only CodeMirror viewers with syntax highlighting and internal scrolling.
  Code blocks retain wrapping, copying, downloading, fullscreen controls, and sticky toolbars.

* **Refined wallpaper surfaces and sidebar contrast**. `change`
  The chat and Settings content areas retain matching translucent wallpaper tints, while the project and Settings sidebars use the solid chat-header surface.
  Message and tool cards remain separate foreground layers, and both themes preserve their intended user-message colors.

* **Simplified Skills and Tools management views**. `change`
  Skills and extensions remain discoverable and readable through Settings without introducing a competing editor for Pi-owned resources.
  Relevant folder actions and source previews remain available.

## Fixes

### Message Delivery

* **Fixed queued user messages disappearing after delivery**. `fix`
  When Pi removes a Steer or Follow-up message from its queue and emits a user-message event, the delivered turn now appears in the transcript.
  Normal prompts still avoid duplicate display when their Pi event arrives.

* **Hardened interruption and session synchronization**. `fix`
  Stop and session transitions wait for correlated Pi responses and authoritative state/history synchronization.
  Interrupted tool calls, retries, and terminal provider failures are represented without treating an RPC acceptance as task completion.

### Chat Performance

* **Reduced work during streaming responses**. `fix`
  Adjacent Pi text and thinking deltas are coalesced over a 50 ms window, while non-text RPC events retain their ordering.
  Composer editing also keeps draft state local, avoiding unnecessary full-transcript rerenders on each keystroke.

* **Improved large conversation and code-output behavior**. `fix`
  Transcript virtualization, incremental CodeMirror document updates, and bounded technical-output viewers limit repeated rendering work.
  Sticky code headers and manual chat scrolling preserve their existing navigation behavior.

### Appearance and Navigation

* **Restored background visibility and consistent theme colors**. `fix`
  Chat wallpaper remains visible through its tint instead of being hidden by a fully opaque pane.
  The Settings and chat tints match, user-message colors are preserved, and the sidebar surfaces remain deliberately opaque.

* **Improved project-list stability**. `fix`
  Missing project directories are omitted from inactive project choices without deleting their Pi sessions.
  Projects and conversations use predictable batch-based Show more / Show less navigation.

## Upgrade Notes

Molten Forge 2.0.0 is the replacement for the legacy Electron application. Install Pi independently and ensure `pi` is available on `PATH`. This release does not include a migration utility for the old Electron application's private settings or session format.

Existing installations of the Tauri development builds named “Molten Forge Pi” may not be detected as upgrades by the renamed Windows installer. Uninstall the old development build before installing Molten Forge if both entries would otherwise coexist; preserve application data if you want to keep settings and attachments. The Tauri identifier remains `com.moltenforge.pi`.
